# Nexa Quant · Paper Trading

Polymarket US 预测市场的**模拟交易**研究项目。只使用虚拟资金，代码中不包含任何下单或账户凭证。

## 运行方式

GitHub Actions（`.github/workflows/scan.yml`）每 5 分钟运行一次：

| 脚本 | 作用 |
| --- | --- |
| `scan.py` | 读取公开行情。优先重新报价持仓和跟踪中的市场，再从一页新市场里补充候选。 |
| `paper.py` | 按“扣除成本后的动量”策略模拟买卖，结果写入 `data.json`。 |
| `news.py` | 抓取 Google News RSS 标题作为参考，仅为关键词关联，不代表因果。 |

`index.html` 读取 `data.json` 展示虚拟资产、持仓、报价和交易记录。

## 策略规则（v3.1）

- 虚拟本金 $3,000，每笔固定买入 $300，最多 10 个持仓。
- 买入条件：与约 60 分钟前（20–180 分钟窗口）的中间价相比上涨 2%–20%，卖价在 0.10–0.85，买卖价差 ≤ 0.01，扣除假设手续费和滑点后的估计优势 ≥ 1%。
- 卖出条件：止盈（+6% 加成本）、止损（−8%）或持有满 48 小时；只按真实的最新买价成交。
- 风控：单日已实现亏损达 $30 或累计达 $100 时停止开新仓。
- 手续费按官方费率表计算：吃单费 = 0.0695 × 份数 × p × (1−p)，四舍五入到分（已于 2026-10-28 核对 [docs.polymarket.us/fees](https://docs.polymarket.us/fees)）。乒乓球市场费率更高（θ=0.10），扫描时直接跳过；组合单不交易。不计挂单返佣和成交量返佣。每边另加 0.5% 假设滑点。
